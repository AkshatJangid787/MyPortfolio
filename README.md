# 🚀 Full Stack Developer Portfolio

A clean, modern, and fully functional developer portfolio showcasing projects and skills with a secure admin panel. The **frontend UI design** was generated using [Lovable AI](https://lovable.so/), while **all other parts including development, backend, integration, and deployment were implemented by me**.

---

## 🛠️ Tech Stack

### 🔹 Frontend
- **React.js** with UI layout from Lovable AI
- **Axios** for API communication done manually
- **Tailwind CSS** for styling
- **Custom functionality and data integration** done manually

### 🔹 Backend
- **Node.js** with **Express.js**
- **MongoDB** for database
- **Mongoose** ODM
- **JWT Authentication** with **Cookie-Parser** for secure admin login
- Full **CRUD operations** for Projects and Skills

---

## 🔐 Admin Panel Features
- Secure login with JWT and HTTP-only cookies
- Add, edit, and delete projects and skills
- Admin-only protected routes

---

## 🌐 Deployment

| Platform   | Details                  |
|------------|--------------------------|
| **Frontend** | Deployed on [Vercel](https://vercel.com/) |
| **Backend**  | Deployed on [Render](https://render.com/) |
